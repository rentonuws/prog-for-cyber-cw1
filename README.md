## Program Description
This program repeatedly asks for a username and password until the correct username and password are entered. An event log is generated for every login attempt, recording both successful and failed authentication attempts.

## Instructions to Run the Program
Ensure you have Python 3 installed on your machine. Follow these steps to run the script:

1. **Clone or download all files from this branch.**
2. **Run event_logger.py from terminal.**
3. **Enter the username and password when prompted.**
4. **Review the event log displayed after each login attempt.**
