This repository is a collection of Python-based security utilities and tools in Coursework 1. This project demonstrates core principles of programming including access controls, login attempts counter, authentication tracking, network IP validation and password validation.

Each task has been developed within its own dedicated git branch, complete with individual documentations, implementation files, and screenshots.


## Project Structure & Git Branches

|Task #  | Task Name | Branch Name | Description |
| :--- | :---      | :---        | :---        |
| **Task 1** | Security Tool | security-tool | A Security tool including an event counter, a Brute-Force simulator, and multi-attempt login authentication.|
| **Task 2** | Security Event Logger | security-event-logger | A program records and prints the event log for each try, including all failed and successful login attempts.|
| **Task 3** | IP Address Validator | ip-address-validator | A function that validates an ip address and will get an appropriate message indicating whether the IP address is valid or not.|
| **Task 4** | Security  Incident Manager | security-incident-manager | A program that stores and updates information about a security incident.|
| **Task 5** | Cyber Security Utilities | cyber-security-utilities | One function to validate IP address, one function to validate password strength and one function to generate a random complex password. |
