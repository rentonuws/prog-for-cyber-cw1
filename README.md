## Program Description
This task implements a function called validate_ip() that performs basic IPv4 address validation.
This function removes unnecessary spaces, checks that the address contains exactly three dots, verifies that there are exactly four numbers and confirms each value is between 0 and 255.The function will return True for a valid IPv4 address and False for an invalid IPv4 address.

## Instructions to Use the Function
Ensure you have Python 3 installed on your machine. Follow these steps to run the script:

1. **Clone or download all files from this branch.**
2. **Import the validate_ip() function into a Python program.**
3. **Pass an IPv4 address string as an argument to the function.**
4. **The function will return True if the address is valid and False if it is invalid.
