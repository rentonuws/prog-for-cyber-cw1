## Program Description
This is a small collection of reusable Cyber Security functions stored in security_tool.py. This program provides reusable Cyber Security utility function for IPv4 validation, password strength checking and random password generation.

## Instructions to Run the Program
Ensure you have Python 3 installed on your machine. Follow these steps to run the script:

1. **Clone all files from this branch.**
2. **Run main.py from the terminal.**
3. **Enter a strong password**
4. **Enter an IPv4 address**
